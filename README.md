# Tienda en línea de artesanías mayas

Proyecto Integrador de Regularización · Multimedia y Diseño Digital
Universidad Politécnica de Quintana Roo · Ingeniería en Software

**Alumno:** Alex Fernando Sanchez Aparicio · **Matrícula:** 202300196

## Descripción
Tienda en línea con visor 3D, probador en realidad aumentada y recorrido
virtual del taller, más un plan de mercadotecnia digital.

## Stack
(Se completa cuando elijas: Laravel + Livewire / Node + React, MySQL 8,
Blender, model-viewer, A-Frame, Python + FFmpeg)

## Estructura
- `/tienda`: aplicación web
- `/modelos-3d`: archivos .blend y .glb
- `/ar-vr`: escenas AR y VR
- `/procesamiento-av`: scripts de audio y video
- `/mercadotecnia`: plan, mapas y piezas de campaña
- `/docs`: documentación, retrospectivas, bitácora de IA
